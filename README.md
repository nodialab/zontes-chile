# Zontes Chile · sitio web

Sitio estático (HTML/CSS/JS sin dependencias) para Zontes Chile, con 11 modelos, comparador, distribuidores y mantenciones.

- `site/`: sitio ya construido, listo para publicar en cualquier hosting estático.
- `_raw/*.py`: generadores (`build.py` páginas, `build_img.py` imágenes, `data.py` contenido). Requieren las fuentes originales (`_src/`, `_raw/cut/`), que no se versionan por peso.

Vista local: `python3 -m http.server 4173 -d site`

## Fuentes y derechos
Datos e imágenes provienen de zontes.cl, zontes.com (global) y del importador Imoto (imoto.cl: fichas y fotos de ZT200-Z2, ZT350T-E y ZT350T-M). Son material de terceros: confirmar autorización antes de publicar.
